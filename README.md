# Inspire Ai Folio

Создай Hero-секцию для лендинга-портфолио специалиста по вайбкодингу. Используй стиль загруженного референса. Темная тема, современный дизайн, градиентные акценты. Заголовок: "Создаю AI-продукты через вайбкодинг". Подзаголовок должен объяснять ценность. Кнопки: "Посмотреть проекты" и "Связаться". Адаптируй под мобильные устройства. Создай блок «Избранные проекты» для лендинга-портфолио специалиста по вайбкодингу.

Используй стиль загруженного референса.

Сделай 3 карточки проектов:

StudyFlow — AI-платформа для персонализированного обучения.

НейроАналитик — AI-сервис для анализа данных.

LaunchPro — лендинг для продукта.

В каждой карточке должно быть:

Название проекта.

Краткое описание (1–2 предложения).

Список технологий (через теги).

Небольшое превью (можно использовать плейсхолдер).

Карточки должны хорошо выглядеть на мобильных устройствах (располагаться вертикально). Создай блок «Что я делаю» для лендинга-портфолио вайбкодера.

Используй стиль референса.

Сделай 4 карточки:

MVP за неделю.

AI-автоматизация.

UI/UX с вайбкодингом.

Интеграции.

В каждой карточке:

Иконка (можно использовать эмодзи или плейсхолдер).

Заголовок.

Краткое описание (2 предложения).

Ключевой результат/выгода.

Блок должен быть адаптирован под мобильные устройства.

Создай блок «Как я работаю» для лендинга-портфолио.

Стиль — как в референсе.

Сделай 4 шага процесса:

Погружаюсь в задачу.

Создаю с ИИ.

Тестирую и улучшаю.

Запускаю и масштабирую.

Оформи в виде горизонтальной timeline на десктопе и вертикальной на мобильных устройствах.

Добавь номера шагов и короткие описания.

Остальное не трогай.
